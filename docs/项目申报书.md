### 项目简介
mtuck 是一个使用 MoonBit 编写、以 `native` 后端原生编译的跨平台**终端剪贴板历史管理器**。它把系统剪贴板从"只有一格、下次复制就覆盖"的临时缓冲区，变成一条**可回溯、可搜索、可固定、可脚本化**的时间线：`watch` 常驻后台记录每一次复制，`list` / `show` / `copy` 在终端里随时找回并写回剪贴板，`pin` / `rm` / `clear` / `stats` 负责治理历史规模。
项目名称取自 **M**oonBit + **tuck**（把东西塞进兜里收起来）：剪下来的片段随手收好，需要时再拿出来。

它面向三类人：
- **终端重度用户与开发者**：复制过的命令、URL、代码片段、提交信息都能按编号或子串找回，`git commit -m "$(mtuck show last)"` 这类组合可以直接用在脚本里；
- **MoonBit 生态的使用者与观察者**：这是少数以"**真正交付给普通用户的跨平台桌面工具**"为目标、而非库或算法移植的 MoonBit 项目，展示了 MoonBit 在系统编程、FFI、异步任务、CLI 工程化方面的能力边界；
- **关注隐私的工具作者**：剪贴板是密钥泄露最容易被忽视的通道，mtuck 默认识别并打码密钥、Token、带口令的连接串，从设计上避免明文进入历史文件。

与常见的 Electron / Tauri 剪贴板管理器相比，mtuck 是一个单二进制、零运行时依赖的 CLI：启动即用，不占后台 GUI 资源，可以在 SSH、tmux、容器等没有桌面环境的地方工作，也能被 shell 脚本和管道直接消费。

### 核心功能范围
- **常驻记录**：`mtuck watch` 按可配置间隔（1–999ms）轮询剪贴板，每次变化立即落盘并打印单行预览，Ctrl-C 退出；
- **跨平台事件源**：macOS 通过 `NSPasteboard.changeCount`、Windows 通过 `GetClipboardSequenceNumber` 走"变更计数快路径"，没有变化时无需读取整段文本；Linux（Wayland / X11）退化为读文本比对；
- **历史模型**：头部永远是最新一条，编号即位置；相同内容的未固定条目自动**去重合并**（`hits` 计数 +1 并提到最前）；默认上限 1000 条，超出后淘汰最旧的未固定条目；**固定条目**永不淘汰、不参与合并；单条上限 256 KiB；
- **内容类型判定与保密**：自动为每条打上 `url` / `dsn` / `jwt` / `secret` / `text` / `empty` 标签；能识别私钥块、`password=` / `api_key=` / `token=` 等赋值、`Authorization` / `Bearer` 头、`sk-` / `ghp_` / `AKIA` 等裸密钥前缀、`scheme://user:pass@host` 连接串；密钥类条目在列表、`show` 与 `--json` 输出中**统一打码**，`-f` 才显示原文，旧版本写入的条目也会按当前规则重新判定；
- **命令行检索**：`list` 支持 `-n/--limit` 截断、`-p/--pinned` 只看固定、`-q/--query` 子串过滤；`show` / `copy` / `pin` / `unpin` / `rm` 支持 `last` / `-1`、`1,3,5` 多选、`2-5` 区间等下标语法，可批量操作；
- **脚本友好输出**：`list --json` / `stats --json` 输出结构化数据，配合 `jq` 可以做类型筛选、固定条目提取、按剪贴板内容反查来源；退出码约定 `0` 成功 / `1` 运行期错误 / `2` 用法错误；
- **健壮持久化**：纯文本 TSV（头部 `mtuck-history\t1`，六列 `ts hits pinned kind is_secret text`），零额外依赖、`grep` / `diff` 友好；每次写入采用"临时文件 + rename"原子落盘，崩溃或 Ctrl-C 不留下半个文件；无法解析的行直接跳过而不影响其余数据；
- **可测试架构**：`history` 包为纯逻辑、不依赖 I/O；`watch` 把剪贴板读取抽象为可注入的 `read` 函数，测试中用假读取器覆盖，无需真实系统剪贴板；
- **工程化配套**：`moon check` / `moon fmt --check` / `moon test` 三件套接入 GitHub Actions 与 CNB 流水线，仓库自带 `pre-commit` hook 自动类型检查；README 提供安装、快速上手、命令一览、环境变量、输出格式、开机自启（launchd / systemd --user / 任务计划程序）等完整文档。

### 预期验收产物
- 可执行程序 `mtuck`：`moon build --release --target native` 产出单一原生二进制，在 macOS、Windows、Linux（Wayland / X11）上均可用；
- 完整可用的命令集：`watch` / `list`(ls) / `show` / `copy`(cp) / `pin` / `unpin` / `rm` / `clear` / `stats` / `help` / `version`，README 中所有示例均可直接复现；
- 可复用的 MoonBit 库代码：`history` 包（`History` 模型、`classify` / `mask`、TSV `encode` / `decode`）与 `watch` 包（`Watcher` / `watch_loop`）可被其他 MoonBit 项目 `moon add` 引入；
- 自动化测试套件：覆盖去重合并、固定与淘汰、类型判定与打码、TSV 编解码、轮询变更检测与错误去重等路径，`moon test --target native` 全部通过，并在 CI 中持续运行；
- 文档：README（含安装、用法、工作原理、项目结构、已知限制、路线图）与生成接口文件 `.mbti`；
- 后续版本验收目标：图片与富文本记录、`list --kind` 类型筛选、fzf / 内置 TUI 交互选择、历史加密存储。

### 移植或参考说明
- 原项目名称：无（原创项目，非移植）
- 本项目许可证：Apache-2.0
- 第三方依赖：
  - [`moonbit-community/proton_clipboard`](https://mooncakes.io/docs/moonbit-community/proton_clipboard)（剪贴板系统读写）；
  - MoonBit 核心库 `moonbitlang/core` 中的 `string`、`env`、`async`、`async/fs`、`debug` 等包。
- 平台相关的"剪贴板变更计数"由仓库内 [platform/stub.c](platform/stub.c) 以 C stub 方式实现：macOS 走 Objective-C 运行时调用 `NSPasteboard.changeCount`，Windows 走 Win32 `GetClipboardSequenceNumber`，其他平台返回 0 由上层自动退化为文本轮询。

与同类工具（Windows 剪贴板历史、macOS 上的 Paste / Maccy、Linux 上的 clipse / CopyQ 等）相比，本项目做了以下重新设计：
- 以**终端 CLI + 单二进制**为交付形态，不做常驻 GUI，可在无桌面环境、远程终端、容器内使用；
- 历史文件刻意选择**纯文本 TSV**而非数据库或二进制格式，保证可读、可 diff、可手工修复，单行损坏不影响整体；
- 把"密钥识别与默认打码"作为**核心默认行为**而不是可选项，并在读取旧数据时按最新规则重新判定；
- 采用 MoonBit 原生包结构组织代码，按依赖方向严格分层（`history` 纯逻辑、`watch` 事件源、`cmd/main` 负责 I/O），使核心逻辑可在任意后端上快速测试；
- 图片支持、模糊搜索、交互式选择界面、历史加密等能力作为明确的后续路线图，不在 0.1 中承诺。

### 与其他赛题候选项目的关系
仓库根部同时包含一个早期实验包 `clipboard_history_cli.mbt`（`Entry` / `History` / `summary` / 上限常量），其模型思路已被 `history/` 包中更完整的实现取代；本申报书以后者（`history/` + `watch/` + `cmd/main/` + `platform/`）为准，旧包仅作为库 API 保留。

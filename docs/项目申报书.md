### 项目简介
mtuck 是一个用 MoonBit 编写、原生编译的跨平台终端剪贴板历史管理器。它把系统剪贴板从一个只有一格、下次复制就覆盖的临时缓冲区，变成一条可回溯、可搜索、可固定、可脚本化的时间线：常驻监听记录每一次复制，随时列出、查看、并写回剪贴板，也负责固定、删除与清理历史规模。项目名称取自 MoonBit 与 tuck（把东西塞进兜里收起来），复制过的片段随手收好，需要时再拿出来。

项目面向终端重度用户与开发者：复制过的命令、URL、代码片段都能按编号或搜索找回，并直接组合进脚本；也面向 MoonBit 生态的使用者：这是少数以真正交付给普通用户的跨平台桌面工具为目标、而非库或算法移植的 MoonBit 项目，展示了 MoonBit 在系统编程、FFI、异步任务和 CLI 工程化方面的能力边界；还面向关注隐私的工具作者：剪贴板是密钥泄露最容易被忽视的通道，mtuck 默认对密钥类内容打码，从设计上避免明文暴露。

与常见的 Electron / Tauri 剪贴板管理器相比，mtuck 是单二进制、零运行时依赖的 CLI：启动即用，不占后台 GUI 资源，可在 SSH、tmux、容器等没有桌面环境的地方工作，也能被脚本和管道直接消费。

### 核心功能范围
- **常驻记录**：后台按可配置间隔监听剪贴板，内容变化立即持久化；macOS 与 Windows 借助系统原生能力轻量判断变化，Linux 自动退化为读取比对；
- **历史模型**：最新一条始终在最前，编号即位置；重复内容自动合并并排序到最前；固定条目永不淘汰，超出容量时淘汰最旧的未固定条目；
- **内容类型判定与保密**：自动区分 URL、连接串、JWT 与密钥等类型，识别私钥块、敏感赋值、认证头、常见密钥前缀与带账号密码的连接串；密钥类内容在列表、详情和结构化输出中默认打码，显式参数才显示原文，旧数据也按最新规则重新判定；
- **命令行检索**：支持条数截断、只看固定条目、子串过滤；条目操作使用统一编号语法，支持最新一条、多选与区间批量处理；
- **脚本友好**：列表与统计支持结构化输出，便于与其他命令行工具组合；退出码区分成功、运行期错误与用法错误；
- **健壮持久化**：采用纯文本格式存储，零额外依赖、可读可 diff、可手工修复；原子写入，中断不产生残缺文件；坏行跳过不影响其余数据；历史文件仅当前用户可读；
- **可测试架构**：历史模型是无 I/O 的纯逻辑，监视器把剪贴板读取抽象为可注入函数，测试不依赖真实系统剪贴板；检查、格式与测试流程接入持续集成。

### 移植或参考说明
- 原项目名称：无（原创项目，非移植）
- 本项目许可证：Apache-2.0
- 第三方依赖：moonbit-community/proton_clipboard（剪贴板系统读写），以及 MoonBit 核心库中的异步、文件系统、环境与字符串等包。

与同类工具（Windows 剪贴板历史、macOS 上的 Paste / Maccy、Linux 上的 clipse / CopyQ 等）相比，本项目做了以下重新设计：
- 以终端 CLI 加单二进制为交付形态，不做常驻 GUI，可在无桌面环境、远程终端与容器内使用；
- 历史文件刻意选择纯文本格式而非数据库或二进制，保证可读、可 diff、可手工修复；
- 把密钥识别与默认打码作为核心默认行为而不是可选项，并在读取旧数据时按最新规则重新判定；
- 按依赖方向严格分层，纯逻辑、事件源与 I/O 相互独立，使核心逻辑可以在任意后端上快速测试。
